# StyleMate

A React app designed to make getting dressed easier. Catalog your wardrobe, organize your clothes by category, and create outfits using pieces you already own. Whether you're dressing for an event or planning your everyday look, StyleMate helps you find the right outfit faster.

## 🚀 Live Demo
https://stylemate-topaz.vercel.app

## Features
- Add clothing items with name, category, color, and image
- Browse wardrobe as a filterable grid (by category)
- Mark items as favorites, delete items
- Edit any wardrobe item's name, category, color, or image inline
- Live item count and empty-state messaging
- Select multiple items and save them together as a named outfit
- Edit a saved outfit's name and swap which items are included
- Delete saved outfits
- View all saved outfits with linked item images
- Random Outfit Generator auto-picks one Top, one Bottom, and one Shoe
- About page explaining how the app works, with tab based navigation
- Dark mode toggle with a glowing title effect
- Custom styled modals for confirmations and validation messages (no plain browser alerts)
- All data (wardrobe, outfits, theme preference) persists across refreshes via localStorage
